# 2026-06-16: 캘린더 종일 일정 인접일 누수 수정 (KST 오늘만 수집)

## 배경

사용자 보고: 캘린더 수집 결과에 **엉뚱한 날 항목이 섞임** (주로 어제 일정).

## 진단

- 날짜 계산은 이미 KST로 정상: `main.py` `now = datetime.now(KST)`,
  `calendar.py`도 `now_kst` 기준 00:00~다음날 00:00 검색창
- cron도 KST 정렬됨 (`11 UTC = 20:00 KST`)
- caldav(`_to_utc_date_string`)는 tz-aware datetime을 `astimezone(utc)`로
  올바르게 변환 → 검색창 자체는 정확
- **근본 원인**: 종일(all-day) 일정은 시간 없이 날짜만 있는 floating 값.
  검색창을 UTC로 변환(KST 00:00 → 전날 15:00 UTC)하는 과정에서, 어제 종일
  일정의 [어제 00:00, 오늘 00:00) 구간이 오늘 창과 겹쳐 **딸려 들어옴**.
  시간 지정 일정은 창에 정확히 걸려 문제 없음.

## 변경

### `src/collectors/calendar.py`

- `_event_on_kst_day(dtstart, dtend, day, kst)` 헬퍼 추가
  - 시간 지정(datetime): KST 변환한 시작~종료 날짜 구간이 `day` 포함 여부
  - 종일(date): iCal `dtend`는 배타적(다음날) → `[dtstart, dtend)` 반열림 구간
    판정 (dtend 없으면 단일 종일로 dtstart+1일)
- 수집 루프에서 이 필터를 통과 못 한 일정은 제외, `dropped` 카운트
- 로그에 `(KST 오늘 아닌 N개 제외)` 표시

### 검증

`_event_on_kst_day` 단위 테스트 8케이스 전부 통과:
오늘/어제/내일/멀티데이 종일 + 시간지정 오늘/어제/멀티데이.
