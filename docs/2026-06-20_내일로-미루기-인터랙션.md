# 2026-06-20: 저녁 '완료' 직후 '내일로 미루기' 인터랙션 (webhook)

## 배경

매일 TODO에서 자동 이월(carryover)을 제거(notion-daily-todo 쪽)하는 대신, 사용자가
저녁에 **직접 고른** 오늘 못한 항목만 다음날로 넘기는 인터랙션을 추가.

## 흐름

기존: tasks 토글 키보드 → 🏁완료 → (체크 동기화 + 피드백) → "오늘 하루 어땠어?" status.

변경: 🏁완료 후 미완료 항목이 있으면 **"내일로 미룰 항목" 키보드**를 한 단계 끼워넣음
→ 고른 항목 저장 → status. 미완료가 없으면 바로 status.

## 변경 (`api/webhook.py`)

- `_handle_done` 끝: 미완료(`not done`) 있으면 `_send_defer_keyboard`, 없으면 기존 status.
- `_build_defer_keyboard` / `_send_defer_keyboard` — 미완료 항목마다 ☐ 토글 버튼
  (`d:{pid}:{idx}`) + "🔜 내일로 넘기기"(`dd:{pid}`).
- `_handle_defer_toggle` — 버튼 ☐/☑ 토글. 선택 상태는 **키보드 마크업에만** 보관
  (별도 저장소 없음, tasks done 상태와 분리).
- `_handle_defer_done` — 마크업에서 ☑ index 수집 → tasks 재읽기로 미완료 목록과 매칭해
  원문 복원 → `_append_deferred_to_daily`로 저장 → status 키보드.
- `_append_deferred_to_daily(client, date, items)` — `{date} TODO` 페이지에
  divider + `🔜 내일로` heading_2 + to_do 항목 append.
- `do_POST` 콜백 라우팅에 `dd:` / `d:` 추가 (`done:`/`d:` 접두 충돌 없음 확인).
