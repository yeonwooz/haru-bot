# 2026-05-05: 날짜별 TODO 페이지 수집 추가

## 배경

기존 `collect_section_todos`는 `2026 할일` 페이지의 `# 할 일` heading 아래
sub-section(매일 아침/주말/매월 1일 등 반복 패턴)만 봤다. 그 페이지의
`# 날짜별 할 일` 섹션 아래로 매일 자동 생성되는 `YYYY-MM-DD TODO` sub-page는
참고하지 않아서, notion-daily-todo가 만든 그 날의 분류된 to-do 목록
(반복 + 캘린더 + 이월 + 빠른시일 추천)이 텔레그램 키보드/일기에 반영되지
않고 있었다.

## 변경

### `src/collectors/notion.py`

- `collect_today_daily_todo_page(today: datetime)` 신규
  - `{YYYY-MM-DD} TODO` 제목으로 글로벌 search → 페이지 id 확보
  - 페이지 안 모든 `to_do` 블록을 카테고리(heading_2) 무시하고:
    - unchecked → 미완료
    - checked   → 오늘 완료 (페이지가 오늘 생성된 것이므로 모든 [x]는 오늘로 간주)

### `src/collectors/__init__.py`

- `collect_today_daily_todo_page` export 추가

### `src/main.py`

- `now = datetime.now(KST)` 변수 분리
- `collect_today_daily_todo_page(now)` 호출
- 기존 `section_uncompleted/section_completed`와 dedupe로 합쳐
  `todo_uncompleted` / `todo_completed`로 사용
  (section과 daily 페이지는 redundant 가능 — 같은 항목 중복 제거)
- summarizer/diary 저장/태스크 키보드 모두 합쳐진 결과 사용
- `_dedupe()` 헬퍼 추가
